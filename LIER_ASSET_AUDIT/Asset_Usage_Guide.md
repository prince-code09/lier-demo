## 4. Technical Asset Specifications & Frontend Optimization

### 4.1. Aspect Ratio Standards & CSS Rules

### 4.2. Next-Gen Format Conversion Targets (Performance / CWV)

Original PNG assets range from **1.70 MB to 2.26 MB** each. Serving these raw files on the web will severely degrade **Largest Contentful Paint (LCP)** and mobile page load speeds.

Recommended automated conversion pipeline:
1. **WebP Conversion:** Target 85% quality. Expected size reduction: **80&ndash;88%** (from ~2.0 MB down to **~180&ndash;280 KB** per image).
2. **AVIF Conversion:** For modern browsers, targeting **~120&ndash;180 KB** per image.
3. **Responsive `srcset` Generation:**
   - Small (Mobile): `480px` wide (~40&ndash;70 KB)
   - Medium (Tablet): `800px` wide (~110&ndash;160 KB)
   - Large (Desktop Retina): `1200px` wide (~220&ndash;300 KB)
